# Создание индексов — UC-06

Во вкладке Schema можно создать индекс на одном или нескольких столбцах, выбрать UNIQUE, порядок столбцов и ASC/DESC. Перед сохранением виден SQL. При ошибке введённые параметры остаются в форме, после успеха список перечитывается из SQLite.

Добавлены модели, SQLite-репозиторий и сервис индексов. Операции используют существующий worker подключений. Сохранение и чтение результата объединены SAVEPOINT, чтобы ошибка не оставляла частичное изменение.

Проверка на Windows, Python 3.14.6 и согласованных версиях Qt/pytest: `python -m pytest -q` — **78 passed**. В том числе проверены настоящие SQLite-файлы, UNIQUE, отмена, сохранение ввода после ошибок, read-only, внешние транзакции и ошибки RELEASE. Установка проекта, `pip check` и запуск `--help` прошли.
