# Удаление индексов — UC-08

В Schema можно удалить пользовательский индекс после подтверждения. Диалог показывает имя индекса и таблицы, данные таблицы остаются. Индексы PRIMARY KEY и UNIQUE-ограничений защищены в интерфейсе и сервисе; пользовательские UNIQUE-индексы можно удалять.

После удаления список перечитывается. При ошибке операция откатывается; если индекс удалили другой программой, интерфейс показывает актуальную схему и причину отказа.

Windows, Python 3.14.6: `python -m pytest -q` — **100 passed**. К предыдущему этапу добавлены 18 проверок SQLite и четыре проверки интерфейса, включая отмену, сохранность строк, защиту ограничений и удаление индекса другой программой. Проверены read-only и откат при ошибке DROP, чтения схемы и RELEASE.
