# Изменение индексов — UC-07

В Schema можно открыть пользовательский индекс, изменить столбцы, их порядок, ASC/DESC и UNIQUE. Имя и таблица сохраняются. Замена старого определения новым выполняется через SAVEPOINT: при ошибке восстанавливается прежний индекс, введённые параметры остаются в форме.

Индексы ограничений и определения с выражениями, WHERE или неподдерживаемыми правилами COLLATE защищены от изменения. Проверка метаданных и DDL выполняются в одной транзакции; чужие незавершённые изменения не фиксируются и не откатываются.

Windows, Python 3.14.6: `python -m pytest -q` — **139 passed**. В том числе реальные SQLite-файлы, нарушения UNIQUE, отказ CREATE после DROP, ошибки RELEASE, read-only, блокировки, точное восстановление SQL и сохранность внешних транзакций. `pip check` и `git diff --check` прошли. Проверена отрисовка главного окна и редактора через нативный Qt windows, штатное закрытие приложения.

Для ручной проверки добавлен `examples/create_index_demo.py`. Изменение индексов выражений, partial-индексов и индексов с явной COLLATE или сравнением, отличным от BINARY, простой формой не поддерживается; просмотр и удаление пользовательских индексов этих видов доступны.
